# Identifier types by channel

Reference for the blacklist lookup table `analytics.pl_identifier_types`.

Each identifier type groups the identifiers that different channels and stores use for a listing. When a new channel or store starts using the app, add its identifiers under the matching type below.

| identifier_type | Identifiers |
|---|---|
| Marketplace Fulfilled SKU | Amazon FBA SKU, Target SKU |
| Listing ID | ASIN, Website product ID, Inventory Item ID, Walmart Item ID, eBay Item ID, Goods ID (Temu) |
| Merchant Fulfilled SKU | FBM SKU, TMU SKU, WMM SKU, PMP SKU, EBM SKU |

## Notes

- First draft of the list, before it was grouped into three types: FBA SKU, ASIN, UPC, Walmart Item ID, FBM SKU, Main SKU, MPN, TMU SKU, SKU ID, Goods ID, Ebay Item ID, EBM SKU.
- Not yet assigned to a type: Main SKU, MPN, UPC, SKU ID.
